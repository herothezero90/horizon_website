some of our previous projects:

Data Management

Web application for restaurant management

Next.js + MySQL + React + Chakra UI (deployed on DigitalOcean)

An administrative dashboard for a restaurant owner was developed to enable defining the current menu, special offer menus, or new menu ideas and subsequently including them in the active menu. Prices, descriptions, and allergens can be edited through a custom desktop and mobile interface. Thanks to integrated instant translations into all necessary languages, menu editing has become simple. An additional functionality is a print-ready PDF menu with a single click.

Data management system for a small medical clinic

PHP + MySQL + JavaScript + Bootstrap

A data management system for a small medical clinic. An internal web application for Lifeline Clinic in Namibia, intended for managing patient databases, medical and visit history, nutrition program databases, and outreach programs. The application is secured so that only clinic staff have access. It allows exporting various data from the database and adding new parameters specific to the operation of a health institution. The design is simple and clean, and data entry is optimized for keyboard use to simulate desktop software.

PROGRAMMING & ART

screenagers vol.2 (visit)

Node.js + JavaScript + WebSocket + HTML + CSS

A platform for creating and managing multimedia performances. Videos, sounds, images, texts, and live streams are defined through an editing interface with the ability to layer media to achieve a complex, time-dependent display. The audience is connected to the server and participates interactively in the stage display via WebSocket. Two classic games that the audience controls with their smartphone are integrated. There is also a "master" interface for directors to manage the entire live performance.

FLIGHT DATA VISUALIZATION

Social network with live flight tracking

Node.js + Express + React + HTML + CSS + JavaScript + Bootstrap + Three.js Globe + WebSocket Chat + Flightlab API + Google Places API

A subscription-based social network with integrated flight data visualization. A 3D globe with a detailed world map and interactive display of flight data. Platform users track flights by entering a flight number, and data is retrieved via the Flightlab API. An integrated direct chat system (1-to-1) among platform users is also included.

QR CODE GENERATOR

QR Code-based transactions

PHP + Yii + MySQL + HTML + CSS + Bootstrap + JavaScript

A QR code generator, scanning interface, and redemption system were developed and added to an existing dating web application. The goal is to allow app users to send gifts associated with physical stores. Stores can scan and redeem QR code-based gifts exchanged by users on the platform.
