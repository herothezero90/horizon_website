upravljanje podacima

Web aplikacija za upravljanje restoranom

Next js + MySQL + React + Chakra UI (deploirano na DigitalOcean-u)

Administratorska nadzorna ploča za vlasnika restorana razvijena je kako bi omogućila definiranje trenutačnog jelovnika, jelovnika s posebnim ponudama ili novih ideja jelovnika i njihovo kasnije uključivanje u aktivni jelovnik. Cijene, opise i alergene moguće je uređivati kroz prilagođeno sučelje na stolnom računalu i mobilnom uređaju. Zahvaljujući integriranim trenutačnim prijevodima na sve potrebne jezike, uređivanje jelovnika postalo je jednostavno. Dodatna funkcionalnost je PDF jelovnik spreman za ispis jednim klikom.

Sustav upravljanja podacima za malu medicinsku kliniku

PHP + MySQL + JavaScript + Bootstrap

Sustav upravljanja podacima za malu medicinsku kliniku. Interna web‑aplikacija za Lifeline Clinic u Namibiji namijenjena vođenju baze pacijenata, povijesti bolesti i posjeta, baze programa prehrane i terenskih programa. Aplikacija je zaštićena tako da joj pristup imaju samo djelatnici klinike. Omogućeno je izvoz različitih podataka iz baze te dodavanje novih parametara specifičnih za rad zdravstvene ustanove. Dizajn je jednostavan i čist, a unos podataka optimiziran je za rad tipkovnicom kako bi se simuliralo desktop softver.

PROGRAMIRANJE I UMJETNOST

screenagers vol.2 (posjeti)

node.js + JavaScript + WebSocket + HTML + CSS

Platforma za kreiranje i upravljanje multimedijskim predstavama. Videozapisi, zvukovi, slike, tekstovi i prijenos uživo definiraju se kroz uređivačko sučelje s mogućnošću slojevitog kombiniranja medija kako bi se postigao kompleksan, vremenski ovisan prikaz. Publika je povezana na poslužitelj i interaktivno sudjeluje u prikazu na pozornici putem WebSocketa. Integrirane su dvije klasične igre kojima publika upravlja svojim pametnim telefonom. Postoji i „master" sučelje za redatelje kojim se upravlja cjelokupnom predstavom uživo.

VIZUALIZACIJA PODATAKA O LETOVIMA

Društvena mreža s praćenjem letova uživo

node.js + Express + React + HTML + CSS + JavaScript + Bootstrap + ThreeJS globe + WebSocket chat + Flightlab API + Google Places API

Pretplatnička društvena mreža s integriranom vizualizacijom podataka o letovima. 3D globus s detaljnom kartom svijeta i interaktivnim prikazom podataka o letovima. Korisnici platforme prate letove unosom broja leta, a podaci se dohvaćaju putem Flightlab API‑ja. Ugrađen je i sustav izravnog čavrljanja (1‑na‑1) među korisnicima platforme.

QR KOD GENERATOR

Transakcije temeljene na QR kodu

PHP + Yii + MySQL + HTML + CSS + Bootstrap + JavaScript

Generator QR kodova, sučelje za očitanje i sustav iskupa razvijeni su i dodani postojećoj dating web‑aplikaciji.
